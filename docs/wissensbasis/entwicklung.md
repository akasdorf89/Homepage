# Geplante Erweiterungen

- Planung: 3 Tiny Houses.

- Abstandsflächen: 3 m wurden thematisiert.
- Geplante Nutzung: Ferienhaus/Beherbergung.
- Flurstück 1602.

## Immobilienstrategie

- Langfristiges Ziel: weitere Ferienwohnungen und Immobilien kaufen und vermieten.
- Dachmarke und Website sollen deshalb von Anfang an skalierbar aufgebaut sein.

## Konsequenz für dieses Repository

`content/objekte.json` führt Objekte und Einheiten als Listen. Ein neues Objekt ist ein
weiterer Eintrag unter `objekte`, eine neue Wohnung ein weiterer Eintrag unter
`einheiten` — ohne Strukturänderung. Die Tiny Houses werden ein eigenes Objekt, sobald
Namen und Daten feststehen.
