# Stammdaten Ferienwohnungsbetrieb

## Betreiber

- Privat bzw. als Einzelunternehmer betrieben; hinter dem Ferienwohnungsbetrieb steht
  nach bisheriger Aussage kein separates Unternehmen.
- Gastgeber/Ansprechpartner: Alexander Kasdorf.

## Systeme und Vertrieb

- **Smoobu** ist als Channel Manager aktiv → technische Anbindung in [`lib/smoobu.mjs`](../../lib/smoobu.mjs).
- Vertrieb über Plattformen, insbesondere Booking und Airbnb.
- Direktbuchungen sollen gefördert werden.
- Kommunizierter Direktbuchungsvorteil: grundsätzlich 10 % Rabatt gegenüber dem
  jeweiligen Plattformpreis.
- Eine eigene, objektübergreifende Homepage ist in Erstellung/Planung — das ist dieses
  Repository.

## Grundstandard Aufenthalt

- Check-in ab 15:00 Uhr, Check-out bis 10:00 Uhr.
- Zugang grundsätzlich über Schlüsselbox; der Code wird kurzfristig mitgeteilt,
  typischerweise einen Tag vor Anreise.
- WhatsApp wird für schnelle Gästekommunikation bevorzugt; E-Mail und
  Plattformnachrichten ergänzen.
- Online-Check-in wird genutzt; abgefragt werden u. a. Name, Geburtsdatum und Adresse.
